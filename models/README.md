# IZK downloaded vehicle models

Place the three Sketchfab ZIP downloads in `models/import/` using these exact filenames:

- `gusheshe.zip` — 1991 BMW 325i (E30) — Pink Slip Kings
- `bmw-lowpoly.zip` — Low-Poly BMW
- `hiace.zip` — Toyota HiAce 2004

The GitHub Actions build extracts them into `src/assets/vehicles/`. Each ZIP must contain `scene.gltf`, its referenced `scene.bin`, and any referenced `textures/` files.

All three supplied models are CC BY 4.0. Keep their original `license.txt` files with the extracted assets and retain the creator/source credits in the game:

- 1991 BMW 325i E30 — micorlov: https://sketchfab.com/3d-models/1991-bmw-325i-e30-pink-slip-kings-f0399f2b18394643bf57d20ba3b72a98
